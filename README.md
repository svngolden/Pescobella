# Pescobella

Static QR menu frontend matching Slanic Moldova design structure (no backend).

## 🚀 Quick Start

```bash
./serve.sh
# Open http://localhost:5173
```

## 🎨 Design Details

- **Fonts**: Poppins (primary), Noto Sans (secondary)
- **Grid**: 2 columns (desktop), 1 column (mobile ≤430px)
- **Colors**: Red accent (#d0312f), Navy (#1f3b5c)
- **Card height**: 140px (desktop), 120px (mobile)
- **Language**: RO/EN switcher (top-left)

## 📱 Responsive

- **Desktop**: 2-column grid, 318px hero
- **Tablet**: 2-column maintained
- **Mobile**: 1-column, 255px hero
